# 网页猫声音频录音工作流

本项目把原始录音放在 `codex-cat-audio-stage/CapturedWebAudio/`，不直接放入 `MeowPlay/Resources/Audio/`。只有完成试听、剪辑、来源确认和安全复核后，才可以导出发布用 `.m4a` 文件。当前首版目录已收敛为 19 个可播放声音，不再要求凑满 40 个文件。

## 当前电脑的检查结果

- 本机没有发现 ffmpeg、OBS、Audacity 或 VLC 命令。
- Windows Sound Recorder 已安装，但它通常从麦克风录音，不能自动证明录到了网页系统音频。
- 本机列出的音频端点是 Realtek 麦克风阵列、Realtek 扬声器/耳机和 Intel 显示器音频，没有发现 Stereo Mix 回环端点。
- 本轮尝试通过 `winget` 获取 `Gyan.FFmpeg.Shared`；查询成功，但 GitHub 下载没有完成，系统当前仍未安装 ffmpeg。不会继续重试这个网络端点。

## 有 ffmpeg 时的录音步骤

在项目根目录运行：

```powershell
.\Scripts\Capture-WebAudio.ps1 `
  -Label "cat_greeting_raw_01" `
  -SourceUrl "https://example.invalid/source" `
  -InputDevice "default" `
  -DurationSeconds 10
```

脚本会先要求确认猫咪是自愿、自然发声，并且没有电视、音乐或其他第三方背景声；之后按 Enter 开始录音，再播放网页音频，录音会在指定秒数后自动结束。输出包括：

- `raw/*.wav`：待审核原始录音；
- `recording-manifest.csv`：标签、来源、录制时间和待确认的版权/安全字段。

如果默认设备没有录到网页声音，可以先用 `-InputDevice` 指定 Windows 音频端点名称。录音前应先做 5–10 秒短样本，确认波形和回放内容，再录正式素材。

## 审核与导入规则

1. 只保留猫咪自然发出的短喵、咕噜或颤音；出现惊吓、痛苦、嘶叫、低吼、持续焦躁或呼吸异常时立即弃用。
2. 逐条试听并记录原始文件名、展示标签、来源 URL、录制人和版权许可。
3. 只有在确认可以全球、永久、商业使用并允许编辑后，才把清单中的 `commercial_rights_confirmed` 和 `editing_allowed` 改为 `yes`。
4. 未审核的 WAV 不得复制到 `MeowPlay/Resources/Audio/`，也不得当作发布素材提交。
5. 通过审核后再剪辑、响度处理并导出 `SoundCatalog.json` 引用的音频文件，最后运行 `Scripts/Validate-ReleaseAssets.ps1`。

网页播放本身不等于取得发布权。若素材来自第三方网页、朋友或下载文件，必须先取得明确的商业使用和编辑许可；不明来源的音频不能进入发布包。
