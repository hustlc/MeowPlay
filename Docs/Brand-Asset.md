# App Icon production record

## Final asset

`MeowPlay/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`

- 1024 × 1024 pixels
- Fully opaque RGB PNG
- Edge-to-edge square artwork; iOS applies the platform mask
- No text, trademarks, or watermark

## Generation method

Created with the built-in OpenAI image generation tool, then resized once with high-quality bicubic interpolation to the required 1024 × 1024 App Store source size.

## Final prompt

> Use case: precise-object-edit  
> Asset type: iOS App Store icon, square 1024x1024 source artwork  
> Input images: Image 1 is the edit target  
> Primary request: remove only the pre-rounded icon mask by extending the existing violet/plum gradient background all the way into all four square corners  
> Constraints: change only the outer background/corners; preserve the cat face, expression, coral ears, three coral sound-wave arcs, colors, lighting, proportions, spacing, and centered composition exactly; the final image must be a fully opaque edge-to-edge square with no rounded corners, no black corners, no transparent pixels, no border, no text, no watermark

The first-generation prompt and original generated source remain in the project handoff conversation. Before public release, the publisher should confirm the icon still fits the final product name and broader brand system.
